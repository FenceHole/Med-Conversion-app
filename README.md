# Med Conversion

A static, single-page reference tool for approximate dose equivalents
between commonly prescribed psychiatric medications:

- **Stimulants** (methylphenidate-class and amphetamine-class agents)
- **Mood stabilizers** (lithium, valproate, carbamazepine, oxcarbazepine,
  lamotrigine, topiramate)

## Use

Open `index.html` in a browser, or deploy the directory to any static host
(GitHub Pages, Netlify, Vercel).

## Disclaimer

Educational reference only. Equivalents are approximate and do not account
for individual pharmacokinetics, tolerance, comorbidities, or interactions.
Cross-titration and serum-level monitoring are required where applicable.
Not a substitute for clinical judgment.
